### 🧠 About Me

I began my career as a **Backend Developer**, building scalable systems and APIs using **Python** and **Django**.  
Over time, I became more interested in the **data side** of software — how data can drive better products, automation, and intelligent decision-making.

Today, I’m focused on **Data Science** and **Machine Learning**, exploring ways to turn raw data into meaningful insights and practical models.  
I work with tools like **NumPy**, **Pandas**, **Matplotlib**, **Seaborn**, **Scikit-learn**, **Jupyter Notebook**, and **Google Colab**.

My backend background gives me a strong sense of structure, scalability, and clean architecture — which I now apply to building data-driven solutions.
